## 🚀 Quick Start

### Step 1: Set Your Admin Password

Add to your `.env` file:
```env
BLOG_ADMIN_PASSWORD=your-secure-password-here
```

### Step 2: Start Your Server

```bash
node server.js
```

### Step 3: Access Admin Panel

Visit: `http://localhost:4242/blog-admin.html`

Login with your password, then you can:
- Create new blog posts
- Edit existing posts
- Delete posts
- All changes appear **immediately** on your website!

## 📝 How to Use

### Creating a Blog Post

1. Go to `blog-admin.html`
2. Click **"+ New Post"**
3. Fill in the form:
   - Title, category, excerpt
   - Image path (use unique images!)
   - Content (supports HTML)
   - Check "Published" to make it live
4. Click **"Save Post"**
5. **Instantly** appears on your blog!

### Editing Posts

1. Click **"Edit"** on any post
2. Make changes
3. Click **"Save Post"**
4. Changes are **live immediately**!
