## The Manual Way (If You Want to Do It Yourself)

### Option 1: Use the Admin Panel (Easiest)

1. **Start your server:**
   ```bash
   node server.js
   ```

2. **Go to:** `http://localhost:4242/blog-admin.html`

3. **Login** with your admin password (from `.env` file)

4. **Click "+ New Post"**

5. **Fill in the form:**
   - Title
   - Category (select from dropdown)
   - Excerpt (short description)
   - Image path (e.g., `Website-Images/Home/example.jpg`)
   - Image alt text
   - Date (format: YYYY-MM-DD)
   - Read time (minutes)
   - URL slug (auto-generates from title, but you can edit)
   - Content (paste your HTML content here)
   - Check "Published" to make it live

6. **Click "Save Post"** - Done! ✅

---

### Option 2: Directly Edit blog-posts.json

**⚠️ WARNING:** Only do this if you're comfortable with JSON!

1. Open `blog-posts.json`
2. Copy an existing post structure
3. Update all the fields
4. **IMPORTANT:** Make sure your JSON is valid (no trailing commas, proper quotes)
5. Save the file
6. Restart your server

**Common Errors to Avoid:**
- ❌ Missing commas between posts
- ❌ Trailing commas after last item
- ❌ Unescaped quotes in content (use `\"` not `"`)
- ❌ Missing closing brackets `]`
